# 포켓몬 도감 퀴즈

**바로 놀기 → https://ian939.github.io/poketmon-quiz/**

책 《포켓몬스터 썬&문 포켓몬 전국대도감》을 읽은 아이가, 단서를 읽고 포켓몬 이름을
맞혀 자기 도감을 채워 가는 게임. 1~7세대 **802마리**가 모두 들어 있다.

일곱 살 아이의 **읽기 연습**이 목적이라서, 모습을 보고 찍는 대신 **글을 읽어야**
맞힐 수 있게 만들었다.

## 처음 시작할 때

캐릭터 20명 중 하나를 고르고 이름을 쓰면 시작한다. 고른 캐릭터와 이름은
홈 화면의 **"도감을 채우자"** 옆에 계속 보인다.

나중에 바꾸려면 홈에서 그 캐릭터를 누르거나, `배지와 기록` 화면의
`캐릭터와 이름 바꾸기`를 쓰면 된다.

## 어떻게 노는가

1. 판에는 `No. ???`와 큰 `?`만 있다. **포켓몬 모습은 보여 주지 않는다.**
2. 아래 단서를 읽는다 — 도감 설명, 타입, 별명(분류), 키·몸무게, 고향, 특성, 진화,
   그리고 **우리 책 몇 쪽에 있는지**
3. 노란 **글자 타일**을 순서대로 눌러 이름을 만든다
4. 맞히면 판이 열려 모습과 도감 번호가 나온다
5. **이름을 따라 쓴다** — 화면 전체가 쓰기 칸으로 바뀌고, 다 써야 다음으로 넘어간다
6. 몬스터볼을 던져 도감에 등록된다
7. 세 번 틀리면 도망가지만 **정답과 모습을 알려 주고**, 나중에 다시 나온다

두 번 틀리면 첫 글자를 알려 준다. 도감에서 아직 못 잡은 칸도 `?`로만 보이므로,
도감을 뒤져 답을 찾을 수는 없다.

## 이름 따라 쓰기 (쓰기 연습)

정답을 맞히면 **패드 전체 크기**의 쓰기 화면이 뜬다. 이름을 한 글자씩,
**획 순서대로** 따라 써야 다음 문제로 넘어간다.

- 왼쪽(가로 화면) 또는 위(세로 화면)의 작은 칸에서 **획 순서 시범이 계속 반복**된다
- 쓰는 칸에는 글자 모양이 홈으로 파여 있고, 지금 그을 획만 빨간 점선·화살표·번호로 표시된다
- ① 번 동그라미에서 출발하지 않거나 방향이 반대면 알려 주고 그 획만 다시 쓴다
- 손을 떼도 그은 만큼은 남고, **멈춘 자리를 다시 짚으면 이어서** 쓸 수 있다
- 다 쓴 획은 초록, 지금 쓰는 획은 노랑으로 보인다
- 한 글자를 마치면 ✓ 가 뜨고 다음 글자로 넘어간다
- **쓰는 동안에는 소리가 나지 않는다** — 획마다 울리면 한 이름에 스무 번이 넘는다.
  잘못 그었을 때는 흔들림과 안내문으로 알려 준다. 퀴즈와 포획 소리는 그대로다

글자 모양은 폰트가 아니라 **자모 획 좌표**로 들고 있어서(`js/write.js`) 안내선과
글자 모양이 항상 일치한다. 초성 → 중성 → 종성 순서로 획을 쌓고, 음절 짜임새
(가로모음 · 세로모음 · 받침)에 따라 자리를 잡는다. `ㅇ`·`ㅎ`의 동그라미는
어느 방향으로 돌아도 인정한다.

802마리 이름 2,659글자 = 획 12,733개가 모두 데이터로 있다. 이름 하나에 평균 16획,
가장 획이 많은 글자는 `뿔`(13획)이다. 한글이 아닌 글자(`♀ ♂ 2 :`)는 획이 없어
자동으로 넘어간다.

## 무엇을 풀지 고르는 방법

**타입 기준**으로 나뉘어 있고, **잠긴 곳은 없다.** 처음부터 아무 타입이나 고를 수 있다.

- **아무 포켓몬이나 풀기** — 802마리 전체에서 무작위로 나온다. 어떤 포켓몬이든 나올 수 있다.
- **타입 골라 풀기** — 풀·불꽃·물처럼 원하는 타입만 골라서 푼다. 18개 타입이 있고,
  순서는 **책이 싣는 순서**(풀 12쪽 → 불꽃 23쪽 → 물 31쪽 → …)와 같아서 책에서 찾기 쉽다.

두 가지 타입을 가진 포켓몬(예: 이상해씨는 풀·독)은 **두 타입 모두에** 들어간다.
그래서 물 타입을 풀다가 잡은 포켓몬이 비행 타입 진행에도 반영된다.

타입마다 20% / 50% / 100%에서 동·은·금 배지를 받는다(배지 54개).

홈 화면의 **802칸 모자이크**는 책과 같은 타입 순서로 놓여 있고, 잡은 포켓몬의
**타입 색**으로 칠해진다. 모을수록 도감이 색으로 물들어 간다.

## 초기화

머리글의 **초기화** 버튼(홈 화면에만 보인다)을 누르면 확인창이 뜬다.
아이가 실수로 지우지 못하도록, 칸에 **`초기화`라고 직접 써야** 지우기 버튼이 켜진다.

## 패드에서 여는 방법

### 방법 1 — 웹 주소로 열기 (가장 간단)

패드 브라우저에서 https://ian939.github.io/poketmon-quiz/ 를 열고,
**홈 화면에 추가**해 두면 앱처럼 바로 열린다. 진행 상황은 그 브라우저에 저장된다.

### 방법 2 — PC에서 띄우고 패드로 접속 (인터넷 없이)

1. PC와 패드를 **같은 와이파이**에 연결
2. **`퀴즈 시작.bat`** 을 두 번 클릭 (검은 창은 열어 둔다)
3. 검은 창에 나오는 `http://192.168.x.x:8080` 을 패드 브라우저에 입력

끝낼 때는 검은 창에서 `Ctrl + C`. `node`가 없다는 오류가 나오면
https://nodejs.org 에서 Node.js를 설치하면 된다.

### 방법 3 — PC에서 그냥 확인

`index.html`을 더블클릭. 크롬·엣지에서 정상 동작한다.

## 담지 않은 것

기술(스킬)·위력·습득 레벨 같은 **배틀 게임 수치는 넣지 않았다.** 책에도 없고,
읽기·쓰기 연습에 도움이 되지 않는다. 진화 조건도 "레벨 36이 되면" 대신
"더 자라면"으로 적는다. 단서와 도감 카드에는 책에 실린 것만 담았다 —
도감 설명, 타입, 분류, 키·몸무게, 고향, 특성, 진화, 책 페이지.

## 진행 상황 저장

브라우저의 저장 공간(localStorage)에 자동 저장된다. **같은 브라우저로 같은 주소**를
열면 이어서 할 수 있다. 브라우저 데이터를 지우거나 다른 브라우저로 열면 처음부터다.

## 디자인

책의 색인 페이지에서 그대로 가져왔다 — 노란 행에 내용이 있고, 오른쪽 흰 칩에 라벨이
있고, 빨간 띠가 구역을 나눈다. 아이가 들고 있는 책과 같은 구조로 읽히게 하려는 것이다.

- 색: 잉크 `#211d16`, 종이 `#fffcf2`, 마리골드 `#f3c13a`, 버밀리언 `#d5372a`, 제이드 `#0f6b5f`
- 글꼴: Black Han Sans(제목·`?`·이름), IBM Plex Sans KR(읽는 본문), IBM Plex Mono(번호·개수)
- 인터넷이 없으면 시스템 한글 글꼴로 대체된다

## 데이터를 다시 만들려면

포켓몬 데이터는 [PokéAPI](https://pokeapi.co)에서 받아 왔다. 다시 만들 필요는 거의 없지만:

```powershell
node tools/build-data.mjs                    # 802마리 데이터 + 원본 일러스트
npm install --no-save sharp                  # 이미지 축소에만 필요
node tools/optimize-images.mjs               # 320px WebP로 줄이기
```

`build-data.mjs`는 응답을 임시 폴더에 캐시하므로 다시 돌려도 네트워크를 거의 쓰지 않는다.
`--no-img`를 붙이면 이미지를 건너뛰고 데이터만 다시 만든다.

고를 수 있는 캐릭터는 4×5로 배치된 시트 한 장에서 잘라 만들었다:

```powershell
python tools/crop-trainers.py [시트.png]     # → images/trainer/01.webp ~ 20.webp
```

배경만 지우려면 '흰색을 다 지우기'로는 안 된다 — 옷·신발·눈의 흰색까지 뚫린다.
그래서 이미지 테두리에서 시작해 **연결된 흰 영역만** 번지듯 훑어(flood fill) 지운다.

20명을 **같은 배율**로 줄여 **같은 크기 캔버스**에 담고 **발끝(바닥선)을 맞춘다.**
캐릭터마다 따로 늘리면 키 비율이 뒤죽박죽이 되고 고르는 화면의 칸 높이도 어긋난다.
픽셀아트라서 줄일 때도 NEAREST로 처리해 또렷함을 유지한다. 원본 시트는
저장소에 넣지 않았다(6MB, 게임에 필요하지 않다).

책 페이지 표는 색인 사진 3장을 판독해 만들었다. 판독 결과 원본이
`data/index-ocr/*.tsv`에 있으므로 합치기만 하면 된다:

```powershell
node tools/merge-book-pages.mjs data/index-ocr/index-266.tsv data/index-ocr/index-267.tsv data/index-ocr/index-268.tsv
```

**이 책은 도감 번호 순이 아니라 타입별로 묶여 있다** — 풀 12~22쪽, 불꽃 23~30쪽,
물 31~45쪽, 벌레 46~54쪽, 노말 55쪽~ 같은 식이다. 그래서 같은 페이지의 포켓몬은
타입을 공유하고, `merge-book-pages.mjs`는 이 성질로 판독을 검증한다:

- 같은 이름에 여러 페이지 값이 오면 **다수결**로 정한다
- 사진이 휘어 판독이 한 행 밀린 경우, 앞뒤 페이지 타입이 맞으면 **자동 교정**한다
- 도감에 없는 이름은 **한 글자 차이**인 이름을 찾아 붙인다 (`줄무마` → `줄뮤마`)
- 그 페이지에 혼자만 있고 앞뒤 타입과도 안 맞으면 **버린다** (틀린 쪽으로 안내하지 않도록)

802마리 중 801마리에 페이지가 붙어 있고, 타입 일관성은 98%다.
검증 결과와 예외 목록은 `data/_*.tsv`에 남는다.
